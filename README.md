### Phase-1
What you'll learn:
├── Linux commands
├── Installing software manually
├── Jenkins CI/CD pipeline
├── Nginx reverse proxy
├── Environment variables & secrets
└── How servers actually work

Time      → 1-2 weeks
Cost      → Free (Azure B1s)
Outcome   → Real URL, Jenkins pipeline working

## Phase-2
What you'll learn:
├── What containers are
├── Write Dockerfile for Java app
├── Write Dockerfile for Angular app
├── docker-compose (run both together)
├── Push images to Docker Hub / Azure ACR
└── Jenkins deploys Docker containers

Time      → 1 week
Cost      → Free
Outcome   → Your app runs in containers
           "docker run" starts everything

## Phase-3
What you'll learn:
├── Deploy JAR directly to App Service
├── Deploy Angular to Static Web Apps
├── Azure managed SSL (HTTPS auto)
├── Custom domain setup
├── Jenkins deploys to App Service
└── Environment variables in Azure portal

Time      → 3-4 days
Cost      → Free tier (F1)
Outcome   → Professional URL with HTTPS
           No server management needed

## Phase-4
What you'll learn:
├── Kubernetes concepts (pods, services)
├── Write deployment YAML files
├── Scale your app (run multiple copies)
├── Load balancing
├── Jenkins deploys to Kubernetes
└── Industry standard DevOps

Time      → 2-3 weeks
Cost      → ~$70-100/month (not free)
Outcome   → Enterprise level deployment
           Same as Netflix, Uber, Google
